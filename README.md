## Publish on GitHub Pages
1. Create a repository (for a root URL name it `YOUR-USERNAME.github.io`).
2. Upload all files and the `images` folder to the repository root.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/` within a few minutes.
